LA TAVERNE · MAQUETTE
Sac : + / − rapides et gestes

Essaie avec le doigt : + et − à droite des objets qu'on a en plusieurs exemplaires ; glisse vers la gauche pour supprimer (avec confirmation) ; glisse vers la droite pour « Utiliser » (une ration mangée = −1) ; appui long pour toutes les options.

Objets

Les gestes proposés
− / + quantité, tout de suite, pour tout objet qu'on peut avoir en plusieurs (rations, torches, flèches, potions…). Un objet unique montre « ×1 » sans boutons ; « + » reste dans l'appui long.
← glisser Supprimer : demande « Supprimer Gourde ? », puis un bouton « Annuler » 5 secondes.
→ glisser Utiliser : retire 1 (ration, potion, flèche) et l'écrit dans l'historique des dés.
appui long Menu : Modifier, Utiliser, Donner à un allié, Équiper / ranger, Dupliquer, Vendre (ajoute l'or à la bourse), Supprimer.
Sur ordinateur : clic droit = appui long. Les boutons restent toujours là pour ceux qui n'aiment pas les gestes.
