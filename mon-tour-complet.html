LA TAVERNE · MAQUETTE
Mon tour complet : le joueur agit, le MJ valide

Essaie : tu peux jouer tout le monde. Le téléphone de gauche suit l'allié dont c'est le tour (Ludo, Korgan, Asterak) ; au tour d'un ennemi, le MJ choisit qui il attaque. C'est d'abord le tour de Ludo (il brille). Touche Ludo → choisis une action → touche la cible (ennemi en rouge, allié en bleu) → « Envoyer ». Sur le téléphone du MJ, valide « Réussi / Raté » (ou fais le jet de sauvegarde). Les dégâts et les effets s'appliquent tout seuls. Les aides aux alliés (Bardic Inspiration, Healing Word) passent sans le MJ ; après une Bardic Inspiration, les Castagnettes du Faux Pas sont proposées. Si un ennemi touche Ludo, il peut réagir (Shield gratuit, Silvery Barbs, Cutting Words).

📱 Le téléphone du MJ

Idée de Xavier (15 nov.) : le joueur gère tout son tour ; le MJ dit seulement si ça réussit. Cette maquette réunit « Mon tour » (action, action bonus, réaction, mouvement), les sorts lancés sur des alliés et le choix de la cible.
Règles gérées dans la démo : une action, une action bonus, une réaction par round ; emplacements de sort ; un seul sort de concentration ; règle 2014 « sort en action bonus → seulement un cantrip en action » ; Bardic Inspiration limitée par ses utilisations.
Personnages, statistiques et créatures de démonstration.
